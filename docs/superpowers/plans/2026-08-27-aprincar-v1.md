# Aprincar V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the Aprincar V1 as a GitHub-organization bundle with a complete local-first PWA platform, extension runtime, official/community game repositories, curriculum mapping and game templates.

**Architecture:** The platform is a React PWA with a small kernel and a browser-safe extension platform. Games are self-contained single-HTML web extensions executed in sandboxed iframes and connected through a MessageChannel SDK; the same game may be streamed online or cached for offline use. Skills/evidence/progress belong to the platform, while games only emit evidence; curriculum mappings are external N:N references.

**Tech Stack:** React 19, TypeScript, Vite, Mantine, Dexie/IndexedDB, Workbox/vite-plugin-pwa, Node 22, GitHub Actions, Playwright/Vitest, Phaser/Three.js templates.

**Spec:** Conversation-approved Aprincar V1 architecture, finalized 2026-08-27.

## Global Constraints

- Core remains local-first and functional without login.
- PWA is optional execution mode, not the product boundary.
- Games are never imported as React components by the App.
- Game code is self-contained and no executable remote code may be loaded by a game.
- Network, camera, microphone and geolocation are denied by default.
- Child progress is calculated by Progress Engine; games cannot set mastery.
- Rewards and pedagogical progress are separate.
- Official, Curated and Community trust levels are represented explicitly.
- BNCC is a curriculum crosswalk layer, not the internal Skill Graph.
- Community contribution is PR + automated gates + human review.
- Code license: AGPL-3.0-only; official educational content: CC BY-SA 4.0; trademarks are separate.
