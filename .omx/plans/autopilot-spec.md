# Autopilot V1.1 specification

Acceptance: all ten official manifests expose unique fantasy and mechanic contracts; direct interaction and adaptive progression are declared; Learning Engine deterministically selects an age/interest/skill-appropriate non-repeating entry; Evidence refreshes the recommendation; App/Hub registries remain integrity-verified; Pages deployment passes.

Non-goals: remote GitHub governance, new cloud services, public API changes, destructive cleanup, or rewriting existing game runtimes.
